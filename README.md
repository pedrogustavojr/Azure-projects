# ☁️ Microsoft Azure - Infrastructure Practices & Labs

Welcome to my central repository for hands-on **Microsoft Azure** labs and projects! 🚀

This space is dedicated to documenting the deployment, configuration, and security of cloud infrastructure environments on Microsoft Azure, applying industry best practices, governance, naming conventions, and cloud security principles.

---

## 🎯 Repository Objectives

- **Hands-on Experience:** Validate theoretical cloud computing concepts in real, functional environments.
- **Documentation & Portfolio:** Register architectures, network flows, validation commands, and visual evidence for each deployment.
- **Continuous Learning:** Build a solid foundation in core infrastructure and gradually advance toward Infrastructure as Code (IaC) and advanced security practices.

---

## 🛠️ Tech Stack & Tools

- **Cloud Provider:** Microsoft Azure (IaaS / PaaS)
- **Operating Systems:** Windows Server / Linux
- **Networking & Security:** Azure VNet, Subnets, Network Security Groups (NSG), Public IP
- **Architecture Diagramming:** Draw.io (Diagrams.net)
- **Version Control:** Git & GitHub
